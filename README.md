# Tic Tac Toe

## Overview
Tic Tac Toe is a classic two-player game where players take turns marking spaces in a 3x3 grid. The goal is to align three of your marks (X or O) horizontally, vertically, or diagonally before your opponent.

## Features
- Two-player gameplay (Player X and Player O).
- Simple game logic implemented in JavaScript.
- Detects wins, losses, and draws.
- Easy to integrate into a frontend or run in a Node.js environment.

## How to Play
1. Players take turns choosing a position on the 3x3 grid (positions are numbered 0-8).
2. The first player to align three of their marks wins.
3. If all positions are filled and no player has aligned three marks, the game ends in a draw.
